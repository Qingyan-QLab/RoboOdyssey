# Bundled Stretch 3 assets

Derived from the pinned Hello Robot Stretch URDF (SE3, Dex Wrist 3, SG3).
The original Clear BSD license is included in LICENSE-stretch_urdf.md.
Source revisions and checksums are preserved in sources.lock.json.

The default fixed-pose avatar is a visual USD with physics removed.
High-level XY/yaw controls, a measured circular collision proxy and logical
pick/place are used; this is not a differential-drive or physical-arm simulator.
The articulated source layers remain included to preserve the complete
profile asset identity. No download or sibling repository is required.
